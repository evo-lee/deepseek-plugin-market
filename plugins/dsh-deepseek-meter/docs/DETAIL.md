# DeepSeek 余额与用量

在会话输入框下方加一颗环境状态小药丸（pill），显示 DeepSeek API 账户余额、今日花费与今日 token 用量。

## 显示什么

- **余额**：调用 DeepSeek 公开接口 `GET /user/balance` 得到的钱包总额，优先取人民币钱包。悬停可看到「余额」以及「充值 / 赠送」明细。
- **今日花费**：把本机今天发生的 DeepSeek 调用按官方价目表折算成金额，例如 `≈¥1.78`：峰值时段的调用按全价、空闲时段按半价分别计价。
- **今日用量**：本机今天产生的 **DeepSeek** 模型调用 token 数（输入 / 缓存命中 / 缓存写入 / 输出），以及调用次数和会话数。悬停可看明细。
- 警示状态：余额低于 5 时左侧圆点与文字转为警示色，并在悬停说明里标出；接口返回 `is_available=false`（欠费）时提示「余额不足，接口可能拒绝调用」。
- 点击药丸立即刷新；后台每 60 秒刷新一次，页面隐藏时暂停、切回时补一次。
- 刷新失败时保留上一次成功读取的数字并标注「刷新失败」，不会把已读到的余额换成 `—`。

## 花费怎么算

- 单价取 DeepSeek 官方价目表（2026-11-18 版，每百万 token）：`deepseek-flash` 峰值为缓存命中 ¥0.04 / 缓存未命中 ¥2 / 输出 ¥8，`deepseek-v4-pro` 为 ¥0.30 / ¥9 / ¥27；空闲时段一律半价。美元价目表同样内置。
- 每条调用按它**发生的时间**判定峰谷，而不是按读取时间。峰值是北京时间周一至周五 09:00–12:00 与 14:00–18:00，其余时间为空闲时段。
- 中国法定节假日同样算空闲时段，但日期每年公布，这里按峰值计算：只会高估，不会漏记。
- 金额按钱包币种显示：人民币账户显示人民币价目，美元账户显示美元价目。
- 价目表可用插件行的 `pricing` 字段覆盖。价目表里没有的模型，金额只累计已定价的部分，并在悬停中标出「未定价模型」，不会静默按更便宜的价格计算。

## 数据来源与凭据

- 余额使用凭据引用 `DEEPSEEK_API_KEY`：优先读 DSH 凭据存储，其次读同名环境变量。密钥只在 Host 侧用于请求 `api.deepseek.com`，不会下发给浏览器。
- 用量来自本机会话日志中模型上报的 usage，只统计 provider 或 model 名称以 `deepseek` 开头的调用，因此同一个 profile 里配置的其他模型提供商不会混进这个数字。分叉（fork）会话从父会话继承的历史事件会被跳过，不会被重复计费。
- DeepSeek 公开 API 没有用量或账单查询接口，所以这里统计的是「这台机器实际发生的调用」，不是平台后台的官方账单口径。
- 余额与用量都不落盘，只在内存里缓存 20 秒。

## 配置

插件行支持四个可选字段（改 `cordis.patch.yml` 里 `deepseek-meter` 这一行）：

| 字段 | 默认值 | 含义 |
|---|---|---|
| `apiKeyRef` | `DEEPSEEK_API_KEY` | 读取余额所用的凭据引用名 |
| `origin` | `https://api.deepseek.com` | API 源站，代理部署时修改 |
| `providers` | `['deepseek']` | 计入「今日」的 provider / model 名称前缀，`'*'` 表示不过滤 |
| `pricing` | 内置官方价目表 | 覆盖单价（见下） |

`pricing` 按币种和模型给**峰值**单价，空闲价自动取一半：

```yaml
config:
  pricing:
    CNY:
      deepseek-flash: { hit: 0.04, miss: 2, out: 8 }
    USD:
      deepseek-flash: { hit: 0.006, miss: 0.3, out: 1.2 }
```

## 已知限制

- 未登录、未配置 API Key 时只显示 `—`，不会显示 0。
- 用量依赖 `sessionQuery` 后端；精简组装里没有该服务时用量显示为不可用。
- 一次只读取最近 7 天内创建的最多 60 个会话日志，超出部分不计入今日合计。
- 「今日」按 Host 的本地时区从零点起算。
- 花费是按官方价目表推算的**估算**值，不是账单；实际扣费以平台后台为准，价格调整或法定节假日会带来偏差。
- 花费只覆盖本机经 DSH 发出的调用；同一把密钥在其它程序里的消耗不计入。
